Clip Autoposter

Clip Autoposter is a personal scheduling tool. It uploads short videos from my own library and publishes them to my own TikTok account at planned times, using the TikTok Content Posting API.

How it works

  1. I connect my TikTok account with Login Kit and grant the video.publish permission.
  2. I add a video file and a caption to the publishing queue.
  3. At the scheduled time the tool uploads the file and posts it to my TikTok profile.
